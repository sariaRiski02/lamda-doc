Console & CLI

LamdaPHP hadir dengan tool Command Line Interface (CLI) bawaan yang sangat kuat. File executable lamda yang berada di root direktori proyek Anda berfungsi untuk mempercepat proses pengembangan melalui fitur pembuat kode otomatis (scaffolding).

1. Menggunakan CLI

Untuk menggunakan CLI LamdaPHP, buka terminal atau command prompt Anda, pastikan Anda berada di direktori utama proyek, dan jalankan perintah menggunakan PHP:

➜ my-lamda-app php lamda [perintah]

2. Perintah Generator (Make)

Saat ini, Kernel konsol LamdaPHP menyediakan tiga perintah sakti yang akan menghemat waktu Anda dalam menulis kode boilerplate dari awal (seperti namespace, class, dan inheritance).

Membuat Controller

Menghasilkan file Controller baru di dalam app/Controllers/.

$ php lamda make:controller NamaController

Membuat Model

Menghasilkan file Model baru di dalam app/Models/ yang langsung mewarisi Core Model.

$ php lamda make:model NamaModel

Membuat Middleware

Menghasilkan file Middleware baru beserta fungsi handle() di dalam app/Middleware/.

$ php lamda make:middleware NamaMiddleware

3. Menjalankan Server Development

Karena LamdaPHP dibangun dengan sangat ringan, Anda tidak perlu web server rumit seperti Apache atau Nginx untuk tahap *development*. Cukup gunakan server bawaan PHP yang diarahkan ke folder public/ Anda.

$ php -S localhost:8000 -t public

Aplikasi Anda kini dapat diakses melalui browser di alamat http://localhost:8000.
