Installation

Memulai proyek baru dengan LamdaPHP sangatlah mudah. Pastikan Anda telah menginstal PHP dan Composer pada mesin lokal Anda sebelum memulai.

LamdaPHP membutuhkan PHP versi 8.0 atau yang lebih baru.

Create Project

Gunakan perintah Composer berikut di terminal Anda untuk mengunduh dan menginstal kerangka kerja LamdaPHP:

Terminal
$ composer create-project lamdaphp/lamdaphp <project-name>

Ganti <project-name> dengan nama folder aplikasi yang Anda inginkan (misalnya: my-app).

Menjalankan Aplikasi

Setelah instalasi selesai, masuk ke direktori proyek dan jalankan server pengembangan bawaan PHP:

$ cd <project-name>
$ php -S localhost:8000 -t public

Secara default, server bawaan PHP berjalan menggunakan satu worker (single-threaded). Hal ini dapat menyebabkan koneksi SSE yang bersifat persisten memblokir permintaan lain. Untuk menggunakan fitur rendering data realtime pada lingkungan pengembangan, jalankan server dengan perintah berikut:

Linux / macOS
$ cd <project-name>
$ PHP_CLI_SERVER_WORKERS=4 php -S localhost:8000 -t public
Windows (CMD)
> cd <project-name>
> set PHP_CLI_SERVER_WORKERS=4
> php -S localhost:8000 -t public

Nilai PHP_CLI_SERVER_WORKERS dapat disesuaikan dengan spesifikasi mesin Anda. Pada contoh ini digunakan nilai 4, yang umumnya sudah cukup untuk kebutuhan pengembangan lokal.
