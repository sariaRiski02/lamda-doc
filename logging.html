Log Writing

Mencatat pesan log ke sistem logging LamdaPHP.

LamdaPHP menyediakan sistem logging sederhana untuk membantu developer mencatat informasi penting selama proses aplikasi berjalan. Logging dapat digunakan untuk debugging, monitoring aktivitas, atau mencatat error sistem.

Gunakan method berikut:

Log::write(string $message)

Method ini akan menulis pesan ke file log aplikasi yang dapat digunakan untuk analisis atau debugging.

Contoh Penggunaan 

Log::write('User berhasil login');

Log::write('Data announcement berhasil dibuat');

Log::write('Terjadi error saat memproses pembayaran');

Kapan Digunakan?

  • Mencatat aktivitas sistem
  • Menyimpan informasi debugging
  • Mencatat error atau exception
  • Monitoring proses penting aplikasi

Cara Kerja

  1. Developer memanggil Log::write()
  2. Pesan diterima oleh sistem logging LamdaPHP
  3. Pesan ditulis ke file log aplikasi
  4. File log dapat dibaca untuk analisis atau debugging
